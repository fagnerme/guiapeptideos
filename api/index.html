API pública de dados

Alfa gratuita, somente leitura e sem chave. Entrega um retrato estático do catálogo; não é uma API de busca em tempo real nem tem garantia de disponibilidade (SLA). O host atual permite leitura de navegador de outras origens (CORS).

Endpoint v1

GET /api/v1/catalog.json — catálogo completo em JSON.

Especificação OpenAPI 3.1

Exemplo

curl https://fagnerme.github.io/guiapeptideos/api/v1/catalog.json

O arquivo contém apiVersion, data e estado da última coleta, fontes oficiais e itens identificados por id. Cada item reúne categoria, fase, situação regulatória, métricas de pesquisa, datas de verificação e estado das consultas. Consultas sem resposta são diferenciadas de resultados vazios; valores anteriores podem ser preservados.

Uso responsável

  • Cacheie o arquivo e consulte a data de coleta e o estado de cada fonte antes de usar os dados.
  • Links e atribuições das fontes acompanham cada registro. Os termos de reutilização variam por fonte; esta API não concede uma licença geral sobre dados de terceiros.
  • Resultados regulatórios dependem de correspondência por ingrediente e cobertura das bases; ausência de resultado não prova ausência de aprovação.
  • Contagens de estudos e artigos não demonstram eficácia. O conteúdo é educativo, não é orientação médica, jurídica ou regulatória.
