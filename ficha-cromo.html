Cromo

Mineral Fase 3

Status regulatório: Nutriente essencial em quantidades pequenas; suplementos não são aprovados como medicamentos para emagrecimento ou controle do diabetes.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

O cromo trivalente é estudado como possível modulador da sinalização de insulina, mas seu papel essencial em humanos permanece discutido.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Baixa para perda de peso ou melhora glicêmica clinicamente relevante; evidência não sustenta uso rotineiro para essas alegações.

Riscos

Desconforto gastrointestinal e cefaleia; relatos raros de dano renal ou hepático, especialmente com produtos concentrados.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
