Substância P

Neuroproteção Pré-clínico (animais)

Status regulatório: Neuropeptídeo endógeno; não é tratamento aprovado para as indicações experimentais associadas a ele.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Liga-se principalmente ao receptor neurocinina-1 (NK1) e participa da transmissão de dor, inflamação e respostas autonômicas.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Alta para seu papel fisiológico; baixa para intervenções terapêuticas experimentais, sem benefício clínico estabelecido como produto.

Riscos

Pode favorecer dor, inflamação, náusea e alterações vasculares; manipular essa via pode ter efeitos sistêmicos imprevisíveis.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
