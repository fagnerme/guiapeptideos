Alexamorelina

Secretagogos de GH Fase 2

Status regulatório: Composto investigacional sem aprovacao para uso humano; o desenvolvimento clínico não estabeleceu uma indicação terapêutica vigente.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Secretagogo de GH da classe dos agonistas de grelina, investigado por seus efeitos sobre apetite, secrecao hormonal e função gastrointestinal.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Baixa; estudos clínicos exploratorios não comprovam eficacia ou segurança para uso geral ou para ganho muscular.

Riscos

Segurança prolongada e interações não estao estabelecidas; a estimulação de GH pode afetar glicemia e retenção de líquidos. Produtos sem controle podem conter contaminantes.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
