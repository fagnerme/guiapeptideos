Capromorelina

Secretagogos de GH Fase 2

Status regulatório: Não aprovada para tratamento humano; ha produtos veterinarios aprovados em alguns países para indicações especificas em caes e gatos. Uso veterinario não autoriza uso em pessoas.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Agonista oral do receptor de grelina (GHS-R1a), capaz de estimular apetite e liberação de GH.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Baixa a moderada para pessoas; estudos humanos foram exploratorios e não estabeleceram uma indicação terapêutica aprovada.

Riscos

Pode elevar glicose e causar sonolencia, vomitos ou diarreia; produtos veterinarios não são formulados nem avaliados para segurança humana.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
