Beta-alanina

Suplemento e metabólito Fase 3

Status regulatório: Suplemento esportivo; não é aprovado como medicamento para melhorar desempenho ou tratar doenças musculares.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Aumenta a disponibilidade de beta-alanina para síntese de carnosina muscular, que contribui para tamponamento de íons hidrogênio durante exercício intenso.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Moderada para melhora pequena em esforços intensos de duração limitada; não melhora de forma consistente todos os tipos de exercício.

Riscos

Parestesia (formigamento) é comum em alguns produtos; não há segurança bem estabelecida para uso prolongado ou em certas doenças.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
