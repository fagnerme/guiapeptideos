Probióticos

Suplemento e metabólito Fase 3

Status regulatório: Categoria ampla de microrganismos vivos; suplementos não são aprovados como medicamentos para todas as doenças. Efeitos dependem de cepa, dose, formulação e indicação.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Podem interagir com microbiota, barreira intestinal e imunidade; mecanismos e efeitos não são intercambiáveis entre cepas.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Moderada para algumas indicações e cepas específicas; insuficiente para recomendar qualquer produto para saúde geral ou substituir tratamento.

Riscos

Podem causar gases; infecções raras são possíveis, sobretudo em prematuros, imunocomprometidos ou pessoas gravemente doentes. Qualidade e viabilidade variam.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
