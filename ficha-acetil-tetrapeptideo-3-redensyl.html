Acetil tetrapeptídeo-3 (Redensyl)

Cosmético In vitro

Status regulatório: Ingrediente cosmético associado a produtos capilares; atenção: Redensyl é uma mistura comercial distinta e não é sinônimo químico deste peptídeo.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Peptídeo usado em algumas formulações capilares, proposto para sinalização ao redor do folículo; mecanismo e efeito sobre crescimento capilar não estão estabelecidos.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Muito baixa — dados independentes sobre acetil tetrapeptídeo-3 são limitados; não há comprovação robusta de tratamento de alopecia.

Riscos

Irritação ou alergia no couro cabeludo são possíveis; composição de misturas e segurança de uso prolongado variam.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
