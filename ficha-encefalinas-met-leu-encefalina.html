Encefalinas (Met/Leu-encefalina)

Opioide Pré-clínico (animais)

Status regulatório: Neuropeptídeos opioides endógenos; não aprovados como medicamentos para administração sistêmica.

O que faz

Sem dados organizados para este item; consulte as fontes.

Mecanismo de ação

Ativam receptores opioides, especialmente δ e também μ, reduzindo transmissão nociceptiva e modulando funções autonômicas.

Benefícios observados nos estudos

Sem dados organizados para este item; consulte as fontes.

Nível de evidência

Alta para função fisiológica; não há eficácia clínica estabelecida para administração dos peptídeos nativos.

Riscos

Riscos farmacológicos da ativação opioide incluem sedação, depressão respiratória e alterações gastrointestinais; estabilidade e distribuição são limitadas.

Protocolo / contexto de uso

Sem protocolo humano validado. Este guia não fornece doses.
